# Manufacturer logos
Put one transparent SVG or PNG logo per manufacturer in this folder. Preferred filenames:
apple.svg, samsung.svg, realme.svg, redmi.svg, xiaomi.svg, oneplus.svg, motorola.svg, poco.svg, oppo.svg, vivo.svg, iqoo.svg, nothing.svg, cmf.svg, asus.svg, google.svg

The homepage and selling flow load these local paths: /images/brands/<filename>.
Use official brand marks or assets you have permission to use. Keep them monochrome (deep teal) or transparent; the card backgrounds are white.
