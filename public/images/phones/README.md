# Smartphone product images
Create a folder for each brand and put the matching phone images inside it:
public/images/phones/<brand-slug>/<model-slug>.webp

Example:
public/images/phones/apple/iphone-16-pro-max.webp
public/images/phones/samsung/galaxy-s25-ultra.webp
public/images/phones/oneplus/oneplus-13.webp

Use clean front/back product shots on a transparent or neutral background. Keep a consistent angle and crop. Recommended WebP, 800 x 1000 px. Model image paths can then be referenced from the catalogue.
