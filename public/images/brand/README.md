# NewTurn brand logo
Place your exact, original NewTurn logo here as:
- newturn-logo.svg (recommended), or
- newturn-logo.png / newturn-logo.webp

The website currently expects /images/brand/newturn-logo.svg.
If you use PNG or WebP instead, update the image path in src/app/page.tsx and src/app/sell/page.tsx.
Use a transparent background. A horizontal logo works best; keep the artwork clear at 170px wide on desktop and 135px on mobile.
