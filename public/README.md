# NewTurn public assets

Brand logo, manufacturer marks and product images belong in the following folders.

## Exact NewTurn logo
`public/images/brand/newturn-logo.svg`
The home and sell pages already reference `/images/brand/newturn-logo.svg`.

## Manufacturer logos
Place transparent SVG or PNG files in `public/images/brands/` with these exact names:
`apple.svg`, `samsung.svg`, `realme.svg`, `redmi.svg`, `xiaomi.svg`, `oneplus.svg`, `motorola.svg`, `poco.svg`, `oppo.svg`, `vivo.svg`, `iqoo.svg`, `nothing.svg`, `cmf.svg`, `asus.svg`, `google.svg`.

## Phone model images
Place product images in `public/images/phones/<brand>/<model-slug>.webp`.
Examples:
- `public/images/phones/apple/iphone-16-pro-max.webp`
- `public/images/phones/samsung/galaxy-s25-ultra.webp`
- `public/images/phones/oneplus/oneplus-13.webp`

Use clean square product images, ideally 900×900 px. SVG logos and transparent PNGs are preferred for manufacturers. Alternatively, upload logos and phone images from Admin → Phone catalogue; their Neon Object Storage URLs are stored with the catalogue records.
